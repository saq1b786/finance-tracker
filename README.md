# Finance Tracker CLI

A command-line personal finance tracker built with Python. Add income and expenses, view transactions, and get a breakdown of your spending by category.

## Features

- Add income and expense transactions with category, description, and automatic date logging
- View all transactions in a formatted table
- Financial summary showing total income, total expenses, and net balance
- Category breakdown showing how much you've spent in each area
- Input validation and error handling throughout

## How to Run

Make sure you have Python 3 installed, then:

```bash
python3 main.py
```

## Built With

- Python 3
- No external libraries — built entirely with the standard library
